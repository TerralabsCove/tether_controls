# Archive

Historical source retained for reference. Nothing in this directory is a
deployment target.

- `legacy_one_motor_bench_firmware/` is the Arduino snapshot used during the
  original one-motor S3 tests. It uses protocol version 1 and is incompatible
  with the active two-motor client and protocol.
- `tether_control_idf/` is the superseded native ESP-IDF experiment.

Current development belongs in `../firmware/tether_control_arduino/`.
