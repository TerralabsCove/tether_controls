Jog

+ is the direction the old end effector docked in. Each move stops and holds if the load reaches the trip or the joint stops moving for the stall time, then holds at no more than 30 %. Speed, torque and load are % of the spec sheet: 100 % is full speed and stall torque.

Dock (ID 2)

New end effector: the over-torque trip hits at 117.1° docking and 14.9° undocking, so these stop 5° and 4° short. Dock moves ID 2 there and holds at the 30 % cap; undock moves it there, then torque off. Moves are whole degrees, so it lands within about 0.5° of the target.

LEDs and endurance

Endurance runs ID 1 ±50° and ID 2 dock/undock. STOP ends it.
